## Installation
1. Double-cliquez sur `AutoClic.exe` (un seul fichier, sans installation de Python).
2. Si Windows affiche « Windows a protégé votre ordinateur » : cliquez sur
   « Informations complémentaires », puis « Exécuter quand même ».
3. AutoClic propose de s'installer (raccourcis Bureau et menu Démarrer, sans droits administrateur).

Les versions sont publiées automatiquement ; ce dépôt ne contient pas le code source.
